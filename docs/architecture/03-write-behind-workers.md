# Asynchronous Workers & Write-Behind Strategy

## Write-Spike Absorption
When a mutation arrives at the API:
1. Validate payload (`input.Validate()`).
2. Update L1 Redis synchronously so the caller sees its own mutation immediately.
3. Enqueue an `AsyncEvent` onto the Redis queue (`internal/repository/redis/async_queue.go` via `redis.EnqueueDB`).

## Batch Persistence (`internal/worker/postgres_batch.go`)
- **Topological Sort (`executionOrder`):** Ensures parent entities are persisted before child entities to avoid foreign-key violations:
  `EntityUser` -> `EntityPasskey` -> `EntityUserSettings` -> `EntitySession` -> `EntityRelation` -> `EntityPost` -> `EntityComment` -> `EntityLike` -> `EntityMedia` -> `EntityPOI` -> `EntityPOIReview` -> `EntityConversation` -> `EntityMembers` -> `EntityMessage`.
- **Fast Path (`pq.CopyIn`):** Bulk insertion via `COPY schema.table (...) FROM STDIN` generated by `generateCopyQuery`.
- **Slow Path & DLQ:** On batch failure, dichotomous retry isolation quarantines failing events into the `postgres_errors` Dead Letter Queue.
- **Denormalized Counters:** Only successfully persisted events trigger `updateCountersPostgres`.

## Maintenance & Algorithmic Workers (`internal/worker/`)
- `algo_time_decay_worker.go` & `algo_trend_worker.go`: periodic score decay and trend recomputation.
- `like_cleanup_worker.go`, `media_cleanup_worker.go`, `reaction_cleanup_worker.go`, `saved_cleanup_worker.go`: orphan cleanup jobs.
- `push_worker.go`: Firebase push notification dispatch.
- `hashtag_canon.go`: hashtag canonicalization.
